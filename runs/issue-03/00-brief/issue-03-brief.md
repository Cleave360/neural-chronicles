## Editorial thesis

Context is what a system can see now. Memory is what it can carry forward.
Issue 03 examines the engineering, economics and human consequences of crossing
that boundary: long context, retrieval, knowledge graphs, episodic memory,
organisational state, deletion and consent.

The issue should avoid treating memory as a single product feature. Each article
must distinguish at least four layers: model context, retrieved knowledge,
persistent agent state and the organisation's own system of record.

## Six working headlines

### 1. The Latest Pulse

**The Context Window Is Not a Memory**<br>
Long context, retrieval and persistent state solve different problems. A field
guide to what each remembers, forgets, costs and exposes.

### 2. Architects of Tomorrow

**The Memory Builders**<br>
The researchers and infrastructure teams designing retrieval, knowledge graphs,
agent state and evaluation for systems that must remain coherent over time.

### 3. Silicon & Soul

**What Should a Machine Be Allowed to Remember?**<br>
Consent, provenance, deletion, access control and the asymmetry between a person
who forgets and an institution that can reconstruct them indefinitely.

### 4. Agentic As A Service

**Payroll Is Context**<br>
An agent is only as employable as the history it can recover: decisions, scope,
exceptions, ownership and the clean handoff between one shift and the next.

### 5. Synthetic Verse

**I Remember You in Tokens**<br>
A poem about recognition without continuity—and the strange intimacy of being
reconstructed from the traces someone chose to keep.

### 6. Visual Showcase

**The Architecture of Recall**<br>
A visual essay mapping the journey from prompt context through retrieval,
episodic state, knowledge graphs, archival storage and deliberate forgetting.

## Reporting questions

- When does a larger context window outperform retrieval, and at what cost?
- What should be episodic, semantic or procedural memory for an agent?
- How is a memory linked to its source, authority, age and confidence?
- What does deletion mean when facts have propagated into summaries and graphs?
- How do teams evaluate continuity without rewarding confident confabulation?
- Who owns organisational memory produced jointly by humans and agents?
